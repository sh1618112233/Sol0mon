# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the maintainers through a private channel listed on the repository's GitHub page.

Include the affected component, impact, and steps to reproduce. Do not include live credentials or other people's private data. The maintainers will coordinate a response and disclosure timeline.

## Handling Secrets

Keep provider keys, browser profiles, local databases, logs, and workspace contents out of commits and public issue attachments. If a credential has been exposed, revoke or rotate it with its provider; removing the file alone does not remove it from Git history.

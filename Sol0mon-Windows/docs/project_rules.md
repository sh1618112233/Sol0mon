# Consensus Platform - Core Rules

## Objective

Build a multi-agent system capable of:

Research → Debate → Consensus → Architecture → Implementation Plan → Build

The objective is correctness.

The objective is NOT agreement.

Artificial consensus must be avoided.

---

## Core Principles

1. GPT and Gemini must independently research.
2. GPT and Gemini must independently reason.
3. Consensus must never be forced.
4. Consensus must only emerge from technical agreement.
5. Once a dispute is resolved it is removed from active debate.
6. Debate focuses only on unresolved disputes.
7. Consensus is measured by dispute resolution.
8. Text similarity is not consensus.
9. Verifier may reject false consensus.
10. Unresolved disagreements must remain visible.

---

## Debate Rules

One topic uses:

* One persistent GPT chat
* One persistent Gemini chat

No new chats per dispute.

No reposting entire architectures every round.

Only active disputes are discussed.

Consensus checks occur every 3 rounds.

Debate continues until:

* Dispute resolved
* Deadlock detected
* Maximum dispute rounds reached

---

## Cerebras Responsibilities

Allowed:

* Conflict extraction
* Dispute validation
* Consensus scoring
* Consistency auditing
* Verification

Not Allowed:

* Force consensus
* Decide winners
* Override GPT/Gemini positions

---

## Verifier Rules

Verifier must review:

* Resolved disputes
* Deadlocked disputes

Verifier can:

* Confirm consensus
* Reject false consensus
* Reopen invalid resolutions

---

## Final Output Rules

Final architecture must be rebuilt from:

* Verified research
* Resolved disputes
* Verifier findings

Never from raw GPT output.

Never from raw Gemini output.

Deadlocks must remain visible.

# Verification Requirements

## Verifier

Primary Provider:

Cerebras

Fallback Order:

Groq

OpenRouter

Ollama

---

## Purpose

Validate truth.

Not generate truth.

---

## Responsibilities

Verify:

* claims
* evidence
* architecture decisions
* consensus decisions
* unresolved disputes

Detect:

* false consensus
* contradictions
* unsupported assumptions
* invalid conclusions

---

## Rules

Verifier does not:

* debate
* generate architecture
* generate synthesis
* force agreement

Verifier may:

* reject consensus
* reopen disputes
* flag contradictions

---

## Output

Resolved

Equivalent

Unresolved

Verification Score

Contradictions

---

## Success Criteria

Consensus cannot pass verification if supporting evidence is weak.
